# Issue 300: lanyon last page diff -- canonical URL index.html stripping (5/6 -> 6/6)

## Problem

lanyon matches 5/6 pages (83%). The single remaining diff is on `index.html`:

```
DIFF index.html (1 differences)
  head > link: attribute_differs
    expected: href='http://lanyon.getpoole.com/'
    actual:   href='http://lanyon.getpoole.com/index.html'
```

The canonical URL for the site's index page includes `/index.html` when it should be stripped to just `/`. The `seo_tag.rs` code at line 363 already has logic to strip `/index.html` from canonical URLs, but this case is not being reached.

### Root Cause Investigation

The SEO tag code (line 354-374 in `seo_tag.rs`) constructs the canonical URL from `site.url` + `page.url`. The stripping logic is:

```rust
if path == "/index.html" {
    "/".to_string()
} else if let Some(prefix) = path.strip_suffix("index.html") {
    prefix.to_string()
}
```

This code is correct for the `(Some(base), Some(path))` match arm. The bug is likely that:
1. The `page.url` for the index page is set to something other than `/index.html` (e.g., `index.html` without leading slash), OR
2. The canonical URL is being set through a different code path (e.g., the page has a `canonical_url` front matter field), OR
3. The `page.url` is not being set at all, causing the `(Some(base), None)` arm to be hit, which doesn't strip `index.html`

The engineer should add debug output or inspect the runtime context to determine which code path is taken for the lanyon index page.

### Cross-Site Impact

This canonical URL stripping issue may also affect other sites. The fix should be generic, not site-specific.
