# Issue 482: Implement jekyll-paginate-v2 plugin

## Problem

jekyll-paginate-v2 extends pagination with autopages (tag/category pages)
and multi-collection support. Sites like made-mistakes use it.

## Scope

Implement paginate-v2 features:
1. Autopages for tags, categories, collections
2. Multi-collection pagination
3. Custom permalink patterns for paginated pages
