# Issue 190: Fix redirect pages to use absolute URLs

## Checklist Category

**Redirect pages use relative URLs instead of absolute** -- 41 pages.

## Problem

Pages generated by `jekyll-redirect-from` use relative URLs (`/community/`) instead of absolute URLs (`https://choosealicense.com/community/`). This affects `<link>`, `<meta>`, `<a>`, and `<script>` elements in the redirect page HTML.

Sample diff (choosealicense.com):
```
link: attribute_differs
  expected: "href='https://choosealicense.com/community/'"
  actual:   "href='/community/'"
```

The `generate_redirect_html` function in `src/main.rs` (line 221) uses `to_url` directly without prepending `site.url`.

## Goal

Prepend `site.url` (and `site.baseurl` if set) to redirect target URLs, producing absolute URLs that match Jekyll's `jekyll-redirect-from` output.

## Affected Sites

- choosealicense.com: 16 pages
- government-github: 11 pages
- jekyll-docs-docs: 14 pages

## Dependencies

None.

## Approach (TDD)

1. Write a test that generates a redirect page for a site with `url: "https://example.com"` and target `/community/`. Assert the HTML contains `href='https://example.com/community/'`.
2. Verify the test fails (currently produces `href='/community/'`)
3. Fix `generate_redirect_html` in `src/main.rs` to construct absolute URLs using `site.url` + `site.baseurl` + target
4. Verify the test passes

## Acceptance Criteria

- [ ] Redirect page `<link rel="canonical">` href uses absolute URL (e.g., `https://choosealicense.com/community/`)
- [ ] Redirect page `<meta http-equiv="refresh">` url uses absolute URL
- [ ] Redirect page `<script>location=...</script>` uses absolute URL
- [ ] Redirect page `<a href=...>` uses absolute URL
- [ ] When `site.baseurl` is set, it is included in the absolute URL (e.g., `https://example.com/docs/page/`)
- [ ] When `site.url` is not configured, falls back to relative URL (graceful degradation)
- [ ] choosealicense.com, government-github, and jekyll-docs-docs DOM matches improve (41 pages total)
- [ ] `cargo test` passes

## Test Scenarios

- **Test `test_redirect_html_all_elements_absolute`**: Verify all four elements (`<link>`, `<meta>`, `<script>`, `<a>`) use the absolute URL.
- **Test `test_redirect_html_no_site_url_uses_relative`**: Site with no `url` configured. Assert relative URL is used (fallback behavior).

### Regression: Other redirect behavior preserved

- **Test `test_redirect_html_structure_unchanged`**: Verify the overall HTML structure of redirect pages still matches Jekyll's format (doctype, lang, meta charset, etc.).
