# Issue 527: jekyll-docs internal links missing trailing slash

## Problem

On at least 2 jekyll-docs pages, internal links are missing trailing slashes.
Jekyll produces `href='/docs/variables/'` but rustkyll produces
`href='/docs/variables'` (no trailing slash). Additionally, one link points to
`/docs/index` instead of `/docs/`.

### Affected pages

- tutorials/navigation/index.html
- tutorials/orderofinterpretation/index.html

### Specific diffs

```
href='/docs/installation/' vs href='/docs/installation'
href='/docs/datafiles/' vs href='/docs/datafiles'
href='/docs/variables/' vs href='/docs/variables'
href='/docs/front-matter/' vs href='/docs/front-matter'
href='/docs/' vs href='/docs/index'
```

## Root Cause

These links come from markdown content like `[variables](/docs/variables/)` or
are generated by the `link` tag / `url` filter. The trailing slash is either
being stripped during URL normalization or the permalink generation is not
adding it for directory-style URLs.

## Scope

Fix URL generation to preserve trailing slashes on internal links when the
permalink style is directory-based (ending in `/`). Also fix `/docs/` vs
`/docs/index` to use the directory form.
